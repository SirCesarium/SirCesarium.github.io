# Portfolio — Cesar Marcano (SirCesarium)

Personal portfolio web. Built with Astro and Tailwind CSS.

## Development

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev

# Lint code
pnpm lint

# Format code
pnpm format

# Build for production
pnpm build
```
